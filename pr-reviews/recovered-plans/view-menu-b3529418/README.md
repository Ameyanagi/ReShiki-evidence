# Canvas controls in the View menu

Native macOS captures use ReShiki 0.16.0 at `b3529418cc96a5ba6273b8b586d9bd2b303e15ff`. The app binary hashes to `04a8f5b9a87ad3a0b4ae6ec8c7a3a692fcf2425fb1eefe490a7f4fc233f37c3f`. The window is 1280 × 852 points including the title bar.

1. Open the [Fischer esterification example](esterification.rsk) and click Fit. Open **View** in the status bar. The canvas and 81% zoom remain in place.
2. From the initially focused Grid row, press Down and Return to turn on the rulers. View regains focus. Open View again, turn on Grid, and reopen it to see both checkmarks. Escape returns focus to View.
3. In **Settings → Drawing**, set **Ruler units** to centimetres while **Drawing Style units** stay in points. The canvas ruler reads centimetres.
4. Open **Page setup…** from View to reach the Publication pages inspector. Choose **Dark canvas** in View to see the checked state and dark drawing surface.
