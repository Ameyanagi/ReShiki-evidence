# Straight rim on an empty standard socket

These native macOS screenshots show the same 15/25 socket at 250% with JACS / ACS and a light Publication canvas. The build is `34891ed5a317569558d41a91bc763d4d68bce720`, using the shared equipment renderer from `ad81ed7b528661b28876c2541a5fe6eae4855abd`. The binary SHA-256 is `29f5a239ec7f87cf104b0b1f29cc134fdd9df9453cb276933c9bb37e96d26712`.

1. Reopen the [saved socket drawing](../equipment-open-rim/accepted-glass-socket.rsk) and fit it. A straight rim spans the empty socket.
2. Choose **Insert equipment** and **Glass stopper, 15/25**. Click near the joint to seat it. Properties identifies the two connected pieces. The clean capture shows the seated stopper and the joint outline.
3. Undo once. Properties lists the socket as **Free** and the straight rim returns. Redo seats the same stopper again.

The PNG and SVG exports use the exact refreshed executable with the same saved socket drawing.
