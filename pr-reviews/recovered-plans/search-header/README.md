# Search in the ReShiki header

These captures use the native macOS app at `82e0d2d921a548015185429c2f3ae1c33e9d7b9a`. Executable SHA-256 `a56e5673dbbff3c289a046405b55e5510da0537d9b694fef112e7b748b6af136`.

1. Open [Esterification.rsk](fixtures/Esterification.rsk), click Fit, and open Search. The palette starts focused. Type benzene to find the template and drawing tool.
2. From the drawing, ⌘K opens Search. Choose Import structure or name. In the name field, type ethanol and a colon. Both ⌘K and ⇧⌘P open Search from that field. Escape returns to the same name. A colon from the drawing opens Search.
3. Choose Export panel from Search. The Import and Export tabs are also available. In Help, both aliases leave focus in Help.
4. Open two copies of the scheme under longer names. Search stays visible after the tab strip in the light and dark interfaces.

The captures use the Publication theme at 81% in a 1280 × 852 point window. The actual renderer tests also cover 1040 × 680 and 1280 × 820 in light and dark.
