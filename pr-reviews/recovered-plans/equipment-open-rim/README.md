# Open side-view rim for a standard glass socket

The comparison uses the same accepted 15/25 socket drawing, reopened without edits at 250% on a light canvas in the native macOS app. Both captures use JACS / ACS with Publication colours. The original app was at `05f9b6796`. The refreshed app was at `dda1770c`, using the shared renderer from `a40534c13`. The PNG and SVG use the refreshed app’s CLI and the same saved drawing.

- `before-reopened.jpg` shows the original filled oval.
- `open-reopened.jpg` shows the short side lips and the gap between them. The hatching starts below the mouth.
- `matching-stopper.jpg` shows a 15/25 stopper seating on the refreshed rim in the authoring draft.
- `mark-another-joint.jpg` shows that **Add joint…** leaves Test snapping and both rim clicks register. The intentionally wide pair is measured and reported as 22.8 mm.
