# Native ChemDraw TLC reference

This original TLC diagram compares starting material, a co-spot, and a reaction mixture. ChemDraw SDK 26.8 saved the binary CDX and CDXML used here. The desktop screenshot comes from opening that same CDX in ChemDraw 26.1 at Actual Size.

The plate contains three lanes with four spots. The first and middle lanes share the high spot. The middle and right lanes share the lower spot. The right-hand spot carries the native rich-text Rf label.

Controlled SDK render measurements show a five-point margin at each side, with lanes centred in equal divisions of the width between those margins. The trapezoid probes use the bottom edge to space lanes, with the position at each Rf measured from the left edge.
