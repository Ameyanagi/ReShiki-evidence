## Friction

1. **Clipboard preparation interrupts the shortcut sequence.** After the first Cmd+C, an immediate Cmd+V showed “A clipboard operation is already in progress” and did not paste. Copy later completed with “Editable drawing and images copied.” The paste needed to be retried. This makes the common Cmd+A → Cmd+C → Cmd+V workflow require an explicit readiness check for a large selection.
2. **Selection and history operations have long visible round-trip delays.** Select All with Properties took about 7 s, Undo about 4 s, and Redo about 18 s. These delays interrupt repeated editing. The machine was heavily loaded, and this check does not isolate application work from CPU contention or automation overhead.
3. **Whole-drawing duplicates overlap at small offsets.** The pasted galleries remained nearly on top of each other after Fit, producing dense text and structure overlays. The inspector's counts were needed to confirm the intended fourfold data size visually.
4. **Dark-canvas label contrast is weak for some existing ink colors.** In `08-dark-templates.png`, some dark green gallery headings and annotations are very low contrast on black, even though light bond strokes and template thumbnails remain visible. This makes those canvas labels harder to inspect in dark mode.
5. **Thumbnail hover tooltips cover part of the canvas.** In the template screenshots, hovering over a tile shows a large name tooltip extending left over the drawing. This can obscure nearby canvas content while browsing templates.
6. **Several visible controls were absent from the accessibility tree.** The inspector tabs, template categories/thumbnails, and ring chooser contents were visible in screenshots but were not exposed as individually usable elements in the returned tree. Those parts of the check required coordinate clicks from the current screenshots.
7. **One observation timed out during the larger paste.** Computer use reported error `-10005: noWindowsAvailable`. Waiting 20 s and retrying observation recovered the existing app window, with the paste already complete. This obscured the exact completion time of that paste.

## Anything not completed or not established

All requested functional steps and all eight named screenshots were completed. No save dialog appeared, so there was no “Don't Save” button to choose. The app was not relaunched after exit.

Exact startup time, exact completion time of the timeout-affected second paste, and continuous scrolling frame rate could not be established from these observations. The timings above explicitly include computer-use overhead. No memory measurements or comparison with another build were part of this check.
