## Not verified and why

- **Star actions and browser destination:** intentionally not clicked, as instructed. No actual star, account action, or external navigation was attempted. Chrome's tab inventory was unchanged; other browsers' complete tab inventories were not independently audited.
- **Mouse-button-held suppression, a modal dialog, every panel/menu type, and every possible text field:** the requested negative checks exercised a non-modal style text field, a canvas context menu, and background status. The other combinations were outside those scripted checks.
- **Other eligibility records and cross-relaunch suppression of an already-asked record:** only the supplied due seed was exercised. The one-time record and no-repeat behavior were verified within a run; the dark relaunch deliberately reset the record to `asking` as instructed.
- **Exact sub-second appearance time:** screenshots bound both light and dark appearances to after 30 seconds and by 35 seconds. Five-second capture spacing cannot establish a more precise onset.
- **Strict title-bar-only activation:** the first computer-use title-bar return did not activate the app, and the corrected light return was captured only as a target-window image. This limits that procedural assertion; later foreground status is proven by desktop menu-bar evidence.
- **Don't Save interaction:** neither Cmd+Q produced a save dialog. The app exited directly, so that choice could not be exercised.
- **Additional `-o` report copy:** the request mentioned a `-o` path but supplied no value. A clarification was requested during the run and no additional destination was received. This report was written to the explicit `real-app/report.md` destination.
