1. Open suzuki-before.rsk. Click the right-hand cycle arc to select the
   whole cycle. Choose Tidy cycle in Properties.
2. Review the proposed layout. Escape discards it and the Undo button
   stays disabled. Choose Tidy cycle again, then Apply.
3. Click an empty part of the canvas to see the result clearly.
   One Undo restores the starting arrangement. One Redo restores Tidy.
4. Save as a separate file. The fixture and the saved copy contain all
   168 atoms, the same 186 bonds, and the same cycle settings, steps and
   roles. A second Tidy reports "The cycle is already tidy".
