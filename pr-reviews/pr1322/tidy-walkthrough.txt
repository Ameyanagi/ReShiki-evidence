Open the Suzuki cycle and select it. Run Tidy catalytic cycle from
the command palette. The preview shows Apply and Discard. Escape
restores the original with Undo disabled. Run Tidy again, then press
Enter. The clean result after deselecting shows the intermediates and
side parts, with separate connections to the visible reversible lane.

A second Tidy presents no preview. One Command+Z returns the original
drawing and leaves Undo disabled and Redo available. All four captures
use the same drawing, framing, theme and zoom.
